# ADR-0001: 项目范围 —— 本地优先的 AI 课堂工作台

- 状态：Accepted
- 日期：2026-08-30
- 决策人：Sofia（AI 提供分析）

## 背景

Classolo 是 1037Solo 生态子项目（定位「一站式上课赋能平台」，域名 classolo.1037solo.com，生态预留端口 4070）。需在「P0 快速可用」与「后期并入生态不重构」之间平衡。

## 面临的选项

A. 直接接生态（Supabase + 统一登录）；B. 本地优先 + 可插拔 Provider，生态接入放最晚。

## 决定

**B**。MVP（P0）：工作台四区布局（左侧导航栏 + 文稿区 + 笔记区 + 双渲染区）、实时录音转文字、AI 实时思维导图、协议化渲染区、课堂 Agent（对话 + 静默）。暂不做清单：录音保存/资源库/复习站/测试站（P1/P2）、生态接入（统一登录/Supabase/邮件推送/宝塔 Web 版，最晚）。终端：电脑优先、平板其次、不做手机。环境：Windows PowerShell + pnpm；多 AI Agent 协作，自进化机制完整启用。技术栈：TypeScript + Next.js 16 App Router + Electron 桌面 exe。

## 理由

上课场景个人使用为主，本地 exe 分发覆盖更多场景；前期时间有限，功能优先。Provider 接口（Auth/Storage/Mail/AI/ASR）保证迁移只换实现不动业务。

## 放弃了什么

P0 无云端同步、无多设备；生态会员/推送能力延后。

## 何时重审

本地功能全部稳定、准备生态接入时（预计 P2 之后）。
