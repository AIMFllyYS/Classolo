react-resizable-panels

当前推荐

通用 resizable panel 层

官网定位：用 Group / Panel / Separator 做可拖拽布局。shadcn/ui 文档原文：“The Resizable component is built on top of react-resizable-panels by bvaughn.” 仓库封装把 v4 的 Group/Panel/Separator 映射为 ResizablePanelGroup/ResizablePanel/ResizableHandle。

核心能力（官网）

  • 嵌套分组：/examples/nested-groups，可在交叉处同时拖多组。
  • 收起：collapsible + minSize + collapsedSize；命令式 collapse() / expand()。
  • 持久化：useDefaultLayout({ id, storage })，默认 localStorage，可换成自定义 LayoutStorage。
  • 键盘：Separator 为可 Tab 聚焦的 splitter，带 WAI-ARIA role="separator"；onLayoutChanged 将键盘输入视为用户交互。
  • 触摸：resizeTargetMinimumSize 按 coarse/fine 指针加大命中区。
  • SSR：有 server-rendering / server-components 示例；百分比默认尺寸可能有轻微移位。

allotment

通用 resizable panel 层

README 定位：React split-pane，外观与 VS Code split view 同源。需 import "allotment/dist/style.css"。Pane 可设 minSize / maxSize / snap / visible。

核心能力（官方 README）

  • 水平/垂直：vertical prop。
  • 收起：visible + snap（吸到零）；onVisibleChange。
  • 比例：defaultSizes；变化走 onChange / onDragEnd。无内置 storage hook。
  • 命令式：ref 上的 reset() / resize([...])。
  • 触摸：README 写明触控设备 sash 反馈区固定 20px；可用 setSashSize 加大鼠标区。
  • SSR：README FAQ「Allotment currently only works in a browser」，建议 Next.js dynamic(..., { ssr: false })。
  • 嵌套：README 无嵌套示例。GitHub issue #799 以 nested allotments 为既定用法讨论（已关闭，称 1.20.2 修复）。
  • 键盘无障碍：官方 README 未描述键盘调节 sash。此项标未核实。

dockview-react

IDE 级 dock 布局层

官网：零运行时依赖的布局管理器，做 IDE 式界面——标签与组、拖放重排、浮动组、弹出窗口、序列化。组件类型含 Dockview（完整停靠）、Gridview（无标签网格）、Splitview（单轴分割）、Paneview（可折叠侧栏）。React 包为 dockview-react（peer react 16.8–19）；底层 dockview → dockview-core。

核心能力（dockview.dev / npm README）

  • 持久化：api.toJSON() / api.fromJSON()。
  • 触摸：README 关键词与特性列表含 Touch & mobile support。
  • 键盘：llms.txt 写明 ARIA roles 与 keyboard navigation。空间键盘停靠属 Enterprise。
  • 收起：Paneview 文档描述为 VS Code 式可折叠窗格。完整 Dockview 还有 maximize / edge groups。
  • SSR / Next.js：本次未在官方文档抓到专门说明。未核实。

flexlayout-react

IDE 级 dock 布局层（调研中的另一强候选）

README：多标签 docking 管理器，标签可缩放、移动、组织。仅依赖 React（peer）。可用 tabSetEnableTabStrip: false 把布局降成无标签 multi-splitter，但模型仍是 tabset/row 树。

核心能力（官方 README）

  • 嵌套：row 内再嵌 row/tabset。
  • 持久化：Model.fromJson / model.toJson()。
  • 触摸：Features 写 Mobile support (iPad, Android)。
  • 键盘：独立 Accessibility 章；splitter 方向键 resize；ARIA separator + valuemin/valuenow。
  • 收起：border tabset autohide、tabset maximize、group pill collapse——不是侧栏 collapsible 那种 API。
  • SSR / Next.js：本次未在 README 抓到说明。未核实。要求容器 position: absolute | relative。

决策历史

2026-08-30

AI 初步推荐 react-resizable-panels（经 shadcn/ui Resizable）。理由：与已定组件库同栈，嵌套分割 / 收起 / 持久化 / 键盘与触摸均有官方 API，gzip 11,141 B 且无运行时依赖；dock 层（dockview、flexlayout）超出固定四区需求。
