三层怎么判

AI 每隔几秒吐出一版更新后的大纲。真正要避免的是整图卸载再挂载（闪烁）。树布局在新增兄弟节点时让旧节点平移，与「DOM/React 身份不变」不是同一件事。

  • 层 A（markdown → 导图）：数据通路最短。markmap 用 D3 keyed join 做 morph，但 key 由遍历序号 + 内容哈希构成，中间插入会漂移。
  • 层 B（专用脑图）：开箱就是脑图。mind-elixir.refresh() 会走 layout + 连线重绘；simple-mind-map.updateData 是本次唯一写明「按 uid 复用节点」的官方 AI 教程 API。后者包体与依赖过重。
  • 层 C（通用画布 + 自研/外挂布局）：节点 id 由我们分配，React 调和未变节点；布局算法可选「钉死旧坐标、只安放新节点」。与 StudySolo 的 @xyflow/react 同栈。

层 B 看过但未做完整卡片：jsmind@0.9.1（2025-12-15，BSD-3-Clause，0 运行依赖，npm 周下载 2.8k）。有 add_node / add_nodes，但没有一份与 simple-mind-map 同级的「AI 依次生成 + uid 复用」官方教程，且 npm 维护者 1 人。

  );
}
